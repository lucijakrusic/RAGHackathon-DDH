# RAG for Humanities Data

This repository is maintained by the **NLP / Text Mining / Computational Linguistics group at the Department of Digital Humanities (DDH), University of Graz**.

The repository provides a shared environment for **experimentation with Retrieval-Augmented Generation (RAG) approaches for humanities data**, with a particular focus on the requirements and characteristics of digital humanities research collections.

## Scope

The repository is intended for exploring and comparing different approaches to RAG, including:

* **Embedding-based RAG** and semantic retrieval using vector representations;
* **Graph-based RAG** for exploiting entities and relationships within humanities collections;
* **Hybrid approaches** combining semantic similarity, structured metadata, and graph relationships;
* RAG over **CSV and other tabular research data**;
* RAG over **XML and TEI-encoded resources**;
* the use of document-level and corpus-level **metadata for retrieval and filtering**;
* different strategies for **document segmentation and chunking**;
* retrieval from historical and multilingual textual collections;
* evaluation of RAG approaches for humanities research questions.

For richly encoded resources such as TEI, the aim is also to investigate how existing scholarly markup and document structure can contribute to retrieval, metadata filtering, provenance, and graph construction.

## Purpose

This repository is primarily an **experimental and research environment**. The notebooks and code are intended to support methodological exploration, teaching, prototyping, and comparison of RAG architectures rather than provide a single production-ready RAG system.

Different datasets may therefore require different decisions concerning document representation, metadata, embeddings, chunking, retrieval strategies, and evaluation.

## Organisation

The repository contains Jupyter notebooks and supporting code demonstrating different stages and variants of RAG workflows, including data preparation, indexing, retrieval, and generation.

As the experiments develop, additional approaches, datasets, evaluation procedures, and examples may be added.
